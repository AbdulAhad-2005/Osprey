## KEY FILES TO FOCUS ON FOR THE GAPS

| What you want to understand | Read these |
|---------------------------|------------|
| **Why edge naming is rigid** | `engagement_graph.py:_node_id()` line 33 + `_ingest_one()` — names are derived from `FindingType` enum + label |
| **Why scoring is static** | `crown_jewels.py` lines 13-18 (hardcoded weights) + `hypothesis_engine.py` lines 20-28 (8 role patterns loaded from JSON) |
| **Why the LLM sees only 7 patterns** | `ingest_promoter.py:apply_ingest_rules()` + `config/ingest_rules.json` — only these rules extract structure from stdout |
| **How open loops are generated** | `open_loops.py` — scans findings for gaps (ips_unscanned, hosts_without_http, sisters_unprobed, etc.) |
| **Why it can't create custom relations** | `schemas/engagement_graph.py:AssetType` enum — only these types exist |
| **Why DarkMoon is more adaptive** | `pentest.md` orchestrator — agent reads context, picks tool, not config-driven |
| **Why Shannon is more flexible** | Shannon's Oracle agent infers relationships between findings dynamically |
| **Why HexStrike is more elite** | AI Decision Engine evaluates probability-weighted tool chains |
