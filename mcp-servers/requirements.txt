# Python dependencies for the MCP tool wrappers (mcp-servers/*/tools/*).
#
# In the Docker stack these are installed inside kali-tools/Dockerfile. 
# Install them here only when running tools in NATIVE mode (no Kali container) — e.g.
# `pip install -r mcp-servers/requirements.txt` into the backend environment so
# the custom Python tools (domain_hunter, js_recon, subdomain_takeover,
# web_contact_harvest, email_permute, shodan_*, tech/wappalyzer) work on the host.
#
# The compiled binaries (nmap, subfinder, httpx, nuclei, ...) are NOT installed
# by pip — provide them via your OS package manager / Kali, or run the kali
# profile. `/tools` (CLI) and platform_tools (MCP) show which are present.

# Exact-pinned, matching backend/requirements.txt (its pip-freeze lockfile —
# the one version actually tested end-to-end) and platform-mcp/requirements.txt,
# cli/pyproject.toml, kali-tools/Dockerfile. This package previously drifted
# across 5 independent constraints (two capped <2, one exact, two with no
# ceiling at all) — a fresh build of the unbounded ones could silently pull a
# breaking mcp 2.0 while the others stayed on 1.x. Bump ALL FIVE together,
# never just one.
mcp==1.28.1
